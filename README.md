# AI Interview Platform

An AI-powered interview preparation platform that helps candidates practice interviews, get AI-generated questions, and receive instant feedback.

## Features

- User authentication
- Resume upload
- AI-generated interview questions
- Interview dashboard
- Answer evaluation
- Score and feedback system
- Candidate progress tracking

## Tech Stack

- React.js
- Node.js
- Express.js
- MongoDB
- JWT
- Tailwind CSS
- Gemini API
